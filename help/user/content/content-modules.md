# Inhaltsmodule

Verwenden Sie Module in [!DNL Adobe Journey Optimizer B2B Edition], um Inhalte aus vorbereiteten Layouts zusammenzustellen. Jedes Modul kombiniert [Struktur](./structure-components.md) und [Inhaltskomponenten](./content-components.md) mit Standardinhalten, die Sie durch Ihren eigenen Text, Bilder und Links ersetzen.

Im Gegensatz zu einzelnen Inhaltskomponenten bieten Module vollständige Abschnitte wie Kopf- und Banner, Karten und Fußzeilen. Fügen Sie der Arbeitsfläche ein Modul hinzu und passen Sie dann seine Komponenten an, anstatt jeden Abschnitt aus einem leeren Bereich zu erstellen.

Module unterscheiden sich von [visuellen Fragmenten](./fragments.md). Ein Modul wird Teil des Inhalts, den Sie entwerfen. Ein visuelles Fragment ist ein gespeichertes Inhalts-Asset, das Sie in E-Mails und E-Mail-Vorlagen wiederverwenden können.

## Registerkarte „Module“

Verwenden Sie die **[!UICONTROL Module]** im visuellen Design für einen der folgenden Inhaltstypen:

* E-Mail - Siehe [_E-Mail-Inhaltserstellung_](./email-authoring.md).
* Landingpage - Siehe [_Landingpage-Design_](./landing-page-design.md).
* Visuelle Fragmente - Siehe [_Fragmentbearbeitung_](./fragment-authoring.md).
* E-Mail-Vorlage - Siehe [_Bearbeiten von E-Mail-Vorlagen_](./email-template-authoring.md).
* Landingpage-Vorlage - Siehe [_Design von Landingpage-Vorlagen_](./landing-page-template-design.md).

![Die Modulkategorien werden neben der Arbeitsfläche für das visuelle Design angezeigt](./assets/modules-left-panel.png){width="600" zoomable="yes"}

## Modulkategorien

Erweitern Sie eine Kategorie, um ein Layout auszuwählen. Diese Layouts bieten unterschiedliche Anordnungen des Abschnittsinhalts, z. B. eine, zwei oder drei Spalten.

| Kategorie | Verwenden |
| --- | --- |
| [!UICONTROL Kopfzeilen] | Stellen Sie Ihren Inhalt mit einem Logo, Navigations-Links und Einführungstext vor. |
| [!UICONTROL Hero] | Heben Sie eine Ankündigung oder Promotion mit einem Bannerabschnitt hervor. |
| [!UICONTROL Kundenreferenzen] | Zeigen Sie Kundenzitate in einem formatierten Abschnitt an. |
| [!UICONTROL Karten] | Ordnen Sie Produkte, Artikel oder andere Inhaltselemente in einem Raster an. |
| [!UICONTROL Teams] | Stellen Sie Teammitglieder, Autoren oder Redner mit Fotos, Namen und Rollen vor. |
| [!UICONTROL Fußzeilen] | Vervollständigen Sie Ihren Inhalt mit Navigations-Links, Social-Media-Links und Rechtstext. |

## Module hinzufügen und anpassen

Beginnen Sie mit einem Modul, das dem zu erstellenden Abschnitt entspricht, und passen Sie dann Inhalt und Stil an. Ersetzen Sie Standardlinks und -text durch Inhalte, die für Ihren Kanal geeignet sind.

>[!NOTE]
>
>Fügen Sie für Marketing-E-Mails einen Ausschluss-Link hinzu und [&#x200B; Sie E-Mail-Warnungen](./add-email.md#check-alerts) bevor Sie die Journey veröffentlichen.

1. Öffnen Sie Ihre E-Mail, Landingpage, Ihr visuelles Fragment oder Ihre Vorlage im visuellen Design-Bereich.

   Die **[!UICONTROL Module]** wird standardmäßig angezeigt.

1. Um die verfügbaren Layouts zu überprüfen, erweitern Sie eine Kategorie.

   Sie können auch das Suchfeld verwenden, um ein Modul anhand des Namens zu finden.

1. Ziehen Sie ein Modul auf die Arbeitsfläche.

   ![Die Modulliste wird nach Suche gefiltert und ein Modul wird auf die Arbeitsfläche gezogen.](./assets/modules-search-drag.png){width="600" zoomable="yes"}

1. Überprüfen Sie die Elemente innerhalb des Moduls.

   Jedes Modul enthält Standardinhalte, die Sie bearbeiten können. Klicken Sie auf _Navigationsbaum_-Symbol ( ![Navigationsbaum-Symbol](../assets/do-not-localize/icon-navigation-tree.svg) ) links neben der Arbeitsfläche, um die Struktur und die Elemente im Modul anzuzeigen.

   ![Der Navigationsbaum zeigt die Struktur und die Elemente des ausgewählten Moduls an.](./assets/modules-navigation-tree.png){width="600" zoomable="yes"}

1. Wählen Sie ein Element im Modul aus, um es anzupassen.

   Sie können den Standardtext ersetzen, Bilder aus Ihren Assets auswählen und Links für Ihre Inhalte aktualisieren.

   Passen Sie **[!UICONTROL ausgewählten Komponente mit]** Registerkarten **[!UICONTROL Einstellungen]** und „Stile“ an.

   ![Im Modul ausgewählte Textkomponente mit Stiloptionen](./assets/modules-select-element-styles.png){width="600" zoomable="yes"}

1. Um ein weiteres Element hinzuzufügen, wählen Sie die Registerkarte **[!UICONTROL Komponenten]** und ziehen Sie eine [Inhaltskomponente](./content-components.md) in das Modul.

   Wenn Sie der Modulstruktur eine Komponente hinzufügen, übernimmt sie standardmäßig den Modulstil. Passen Sie die Stile nach Bedarf an.

   ![Eine Textkomponente, die mit formatiertem Platzhaltertext auf die Modulstruktur gezogen wurde](./assets/modules-select-element-add-component.png){width="800" zoomable="yes"}

1. Klicken Sie **[!UICONTROL Speichern]**, um Ihre Änderungen zu speichern.

>[!NOTE]
>
>Wenn ein Markendesign auf E-Mail-Inhalte angewendet wird, übernehmen Module dessen Stile. Informationen zum Einrichten von Designs und Überschreiben von Stilen finden Sie unter [Verwenden eines Designs für die Inhaltserstellung in E-Mails](./brand-themes.md#use-email-theme).

## Wiederverwenden benutzerdefinierter Modulinhalte

Um ein benutzerdefiniertes Modul aus einer E-Mail- oder E-Mail-Vorlage wiederzuverwenden, [speichern Sie den Inhalt als visuelles Fragment](./fragments.md#save-a-new-fragment-from-email-or-template-content). Fügen Sie das Fragment dann in andere E-Mails oder E-Mail-Vorlagen ein.

Für Module, die beim Erstellen eines visuellen Fragments hinzugefügt werden, speichern und [veröffentlichen Sie das Fragment](./fragments.md#create-fragments). Dadurch kann es wiederverwendet werden.
